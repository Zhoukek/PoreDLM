# Distribution status

PoreKmer is a local project package. It has not been published to PyPI, and the
public availability or exclusivity of the name has not been established.
Install the supplied local source directory or wheel, not an unrelated package
with a similar name from a package index.

No open-source license has been assigned by this packaging change. Before public
distribution, the project owner should choose an appropriate license and confirm
the rights to redistribute the code. This notice does not grant a new license.

The source distribution includes documentation, examples, and synthetic tests.
The wheel contains the standalone Python implementation and the console entry
point. Neither distribution includes sequencing data, model checkpoints, the
V003 foundation model, or the parent Motor project.

Packaging metadata follows the [Python Packaging User Guide](https://packaging.python.org/en/latest/guides/writing-pyproject-toml/).
