# Stage 2: Continuous BERT

Set `data.train.directory` and `data.valid.directory` to the feature
directories generated by Stage 1. The model receives `[B, length, 768]`
continuous embeddings, masks feature positions, and predicts the original
continuous vectors. There is no tokenizer codebook, vocabulary, token ID, or
token classification head. Stage 1 is frozen before these features are
generated.

The expected input directory is the output of
`stage1_cnn_train/run_extract_features.sh`; configure it in
`runs/continuous_bert/config.yaml`:

```yaml
data:
  train:
    directory: /path/to/features/train
  valid:
    directory: /path/to/features/valid
```

The BERT checkpoint is also saved in Hugging Face format under the configured
output directory.

```bash
bash runs/continuous_bert/run_train.sh
```

The launcher uses `torchrun`; set `CUDA_VISIBLE_DEVICES` and
`NPROC_PER_NODE` to match the available GPUs.
